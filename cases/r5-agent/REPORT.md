## 回零与异常

API 完成入盘后，显式抬高回撤并完成第一段折叠。回零期间一次 HTTP 上传超时，重试成功；随后完整图片历史使请求体达到 **34,658,807 字节（33.05 MiB，46幅图）**，接口返回 **413 request_too_large**。框架整体 status=error，因此不能把它标为“API 全程含回零无干预成功”。

API 回程计时 238.48 秒。按用户指示，Codex 在原控制进程中检查图像与读回，经原限速／几何检查完成最后折叠、闭合空爪，再释放 SDK。没有重新接管 CAN、自动从低位折叠或人工托臂重摆。

协调者恢复含现场等待共 448.75 秒；真实恢复运动2段、214小步。最终六关节最大绝对读回0.043rad，低于0.1rad容差，空爪已闭合。SDK_RELEASED 事件及控制进程退出已确认。

回程4次HTTP尝试（3次逻辑请求）：2次正常模型完成、2次失败，其中1次重试。已返回用量对应估算 **$0.0334**；两个失败请求没有usage，实际是否计费未知，不填0。准备阶段另外3次API调用约 **$0.0261**；Codex开发和整理未混入Claude控制API用量。
