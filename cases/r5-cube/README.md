这是一次真实 R5 左从臂实验的静态记录。任务完成后，木块完整地留在蓝色盘子内部，
空夹爪撤离，机械臂回到折叠位，SDK 正常退出。单次完成不代表重复实验成功率。

- `data.json`：41 次策略观测、读回状态、下一条动作及切分回复；只导出案例需要的字段。
- `annotations.json`：中文阶段和阅读提示，根据原始运行记录整理，原始动作说明仍在数据中。
- `images/01-fixed.webp` 至 `images/41-wrist.webp`：82 张原尺寸、像素无损相机图。
- `images/*-depth.webp`：7 次额外深度核验的派生伪彩色图，光轴距离色标固定为 5–35 cm。
- `images/final.webp`：控制程序退出后，重新拍摄的最终照片。
- `thumbs/`：缩小的导航图，不作为精细视觉判断依据。
- `fixed.mp4`、`wrist.mp4`：1555 帧、20 fps、77.75 秒；省略策略等待的墙钟时间。
- `provenance.json`：原 EvalLog 的 SHA-256，以及源 PNG、已发布无损图的 SHA-256。
